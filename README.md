# NBA Quarter Predictor

Predicts the winner, point spread and total points for each quarter of an NBA game.

**Open the app:** https://derickmthozi-ops.github.io/nba-quarters/

On a phone, open that link in Safari (iPhone) or Chrome (Android) and use **Add to Home Screen** to install it like an app.

The files at the top level are the web app. `predictor/` holds the Python code that downloads the data and trains the models; see `predictor/README.md`.
